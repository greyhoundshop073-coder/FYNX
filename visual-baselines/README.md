# FYNX visual/layout baselines

This directory is reserved for **approved FYNX reference screenshots**.

The regression gate compares approved PNGs against screenshots captured from
the real CI emulator. It checks image dimensions and changed pixels and can
block a push when an approved surface changes beyond its threshold.

Do not use WhatsApp/Telegram/Facebook screenshots as FYNX baselines. They can
be design references, but the baseline must be an approved FYNX screen.

No baseline images are included yet, so the first rollout is intentionally
PENDING rather than pretending an unapproved current UI is correct.
