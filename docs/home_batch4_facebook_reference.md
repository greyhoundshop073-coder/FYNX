# FYNX Home Batch 4 — Facebook reference notes

FYNX uses mature social patterns as product references, not as a visual copy.

- Feed should prioritize relevant, meaningful interactions and allow users to shape what they see.
- Comments should be easy to enter, read, refresh, and retry without losing the feed context.
- Replies should be organized as conversations rather than a flat wall of text.
- Creation controls should stay discoverable without cluttering the main feed.
- Audience/privacy controls should remain visible at publishing time.
- Save, share, reactions, and discovery should be durable server-backed interactions, never UI-only state.

Reference: Meta/Facebook product and engineering material reviewed for this batch, including Feed ranking, Feed controls, Friends, and the 2025 commenting/creation refresh.
