# FYNX Security Notes

Production security work must preserve the existing authentication, privacy, messaging, media, and backend authorization systems. Review and strengthen those systems; do not replace them with mock or client-only security.

Security release checks: authenticated API transport, backend authorization, input validation, safe error handling, protected local secrets, HTTPS/TLS, AI capability/data-scope enforcement, media ownership/privacy enforcement, production dependency hygiene, and absence of debug secrets.
