# FYNX Chat Upgrade Backlog

This file is intentionally separate from Chat V1 completion.

Items in this file do **not** mean Chat is incomplete. They are candidates for later, explicitly approved upgrades after Chat V1 is certified.

Potential examples from comparison research:

- scheduled messages/reminders
- disappearing messages
- view-once media
- Chat Lock/private chat vault
- advanced cross-chat search/filtering
- richer saved-message workflows
- advanced group topics/community tools
- additional linked-device/multi-device capabilities
- AI-assisted message tools

Research reference: mature messengers continue to add capabilities such as scheduled messages, searchable/filterable history, multi-device synchronization, and disappearing/view-once messaging. Those are useful product references, but they are not automatically part of FYNX Chat V1. The V1 contract decides completion.

Rule: never move an item from this backlog into V1 implicitly. An upgrade requires explicit product approval, a defined acceptance contract, implementation, regression verification, APK verification, and its own controlled push batch.
