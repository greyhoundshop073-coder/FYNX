# FYNX

FYNX is a simple all-in-one social and everyday-life app that brings AI assistance, private messaging, friends, Stories, groups, money tools, daily planning, safety protection, and personalization into one clean and easy-to-use experience.

## Required engineering guidance

**All chats and developers must follow the project-wide [Reference-to-Implementation Engineering Standard](REFERENCE_TO_IMPLEMENTATION_STANDARD.md) whenever a user supplies an image or asks for an interface to match a reference.**

The repository's [AGENTS.md](AGENTS.md) makes this requirement explicit for coding agents. The standard covers reference measurement, existing-code investigation, complete layout planning, real functionality, screenshot comparison, responsive behaviour, regression tests, and honest completion evidence. Read it before starting reference-based UI work.
